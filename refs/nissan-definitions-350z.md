# Pytrex/NissanDefinitions: 350Z coverage

Repo: https://github.com/Pytrex/NissanDefinitions (RomRaider ROM definitions for SH7055/SH7058 Nissans; last commit 2026-06-23). The repo has no LICENSE file, so **we reference it rather than copying it in.** Fetch it with
`git clone https://github.com/Pytrex/NissanDefinitions` and run `Combine All.bat` (or use the latest release's `NissanDefinitions.xml`).

- Tables come from an official Nissan/Renault A2L template (~221 tables). Per-ROM files hold only addresses, and **definitions inherit** via `<rom base="…">`.
- Definitions were generated by binary diffing, so treat any address as *probably* right and verify it against our dump.

## 2003 350Z ROMs and what they inherit

| ROM | Market | Trans | HWID/caseid | Inherits from | Defined tables |
|---|---|---|---|---|---|
| **CD700** | **EU** | MT ("Track") | 4TTZVEM41N1 | **CF170** | 127 (via CF170) |
| **CD800** | **EU** | MT | 4TTZVEM41N1 | **CF170** | 127 (via CF170) |
| CF170 | EU 2003 | ? | 4TTZVEM41N1 | A2L | **127 tables** |
| CD405 | JDM | MT | 2WLGHD10 | CD415 | 105 (via CD415) |
| CD415 | JDM | AT | 2WLGHD10 | A2L | 105 |
| CD000 | USDM | MT | 3GIGGN02 | A2L | checksums only (stub) |
| CD001/2/3, CD006/7/8 | USDM | MT | 3GI… | CE406 etc. | thin |

**ADM inference:** the ADM 350Z was rated **206 kW**, the same as the EU car (280 PS), while the US car made 287 hp. CD700/CD800 are EU 2003 manuals. So an ADM manual is **likely CD700/CD800 or a sibling in the 4TTZVEM4… family**. Confirm with the EPC VIN lookup.

## CF170 tables (what we can tune if we're on CD700/CD800)
Ignition: High Octane Ignition Timing Map (16×16) + Knock Window · High Detonation Ignition Timing Map + Knock Window · Cold Ignition Timing Map + Knock Window · MBT Flame Speed Map · Idle/Cold-idle/Lean-burn idle timing · Initial Retard tables · K1 (accel retard) / K2Y (decel advance) · Knock Slice Map

Fuel/air: Target AFR Map (8×8) · Target AFR Table (High Detonation) · Fuel Compensation Map (16×16) · Accel/Decel Fuel Compensation · **MAF Table** · MAF Factor · **K-Value** · Injector Latency (14 V + adder) · Minimum Injector PW · Cranking Base Fuel · Individual Cylinder Fuel Trims · Cylinder Fresh Air Rate · Cylinder Filling-Up Efficiency Scaler · Closed→Open Loop Delay · fuel cut/restore tables (Bosch/JECS, low oil temp)

Cam/throttle/torque: **Intake Cam Timing Map (16×16)** · Cold Intake Cam Timing (8×8) · Target Throttle Valve Opening (+ Trustful) · Throttle Flow Potential tables · Throttle Body Opening Area Calibration · Engine Torque Map · QH0 Torque Conversion maps · APO Threshold (Brake)

Limits/misc: **Rev Limit (Fuel Cut – 3D)** · **Speed Limiter** · Target Idle RPM · MAF idle voltage limits · Misfire diagnosis maps · DTC 1–18 enable flags

## Checksums (per definition)
| ROM | alt (range → sum/xor loc) | std (range → sum/xor loc) |
|---|---|---|
| CF170 (CD700/CD800) | 0x1408–0x2FDA → 0x1400 / 0x1404 | 0x0–0x7FFFF → 0x63B8 / 0x63B0 |
| CD415 (CD405) | 0x1408–0x3186 → 0x1400 / 0x1404 | 0x0–0x7FFFF → 0x6640 / 0x6638 |
| CE406 (CD003…) | 0x1408–0x30CA → 0x1400 / 0x1404 | 0x0–0x7FFFF → 0x65C0 / 0x65B8 |
| CD000 | 0x1408–0x30CA → 0x1400 / 0x1404 | 0x0–0x7FFFF → 0x67AC / 0x67A4 |

RomRaider uses these to fix checksums on save. **We still verify independently** (32-bit sum + XOR of big-endian u32 words, excluding the stored locations) before every flash.
